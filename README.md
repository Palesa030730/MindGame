# MindGame

MindGame is a Java-based memory and letter-guessing game developed as a web application. Players are challenged to remember and select letters in the correct sequence while earning points for successfully completing the game.

## About the Project

The goal of MindGame is to provide a simple and interactive game that tests a player's memory, concentration, and ability to follow sequences.

Players enter their details, select a difficulty level, and complete a letter sequence. Successful games are awarded points, which are recorded and displayed on a leaderboard.

## Features

* Player name and student ID registration
* Three difficulty levels:

  * **Easy** – 6 letters
  * **Medium** – 15 letters
  * **Hard** – 21 letters
* Randomized letter sequences
* Letter sequence validation
* Game-over functionality
* Winner screen
* Player scoring system
* Leaderboard for displaying player scores
* Session-based player information
* Database storage for scores

## How It Works

1. The player opens MindGame and starts a new game.
2. The player enters their name and student ID.
3. A difficulty level is selected.
4. The game generates a sequence of letters.
5. The player selects the letters in the correct order.
6. A successful game awards points to the player.
7. The player's score is saved and displayed on the leaderboard.

## Scoring

Players earn points when they successfully complete a game.

Scores are stored and displayed on the leaderboard, allowing players to compare their results.

## Getting Started

### Prerequisites

To run MindGame locally, you will need:

* Java JDK
* NetBeans IDE
* GlassFish Server
* SQL database
* A configured database connection

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Palesa030730/MindGame.git
```

2. Open the project in NetBeans.
3. Configure the required database connection.
4. Configure GlassFish Server.
5. Build the project.
6. Run the application.
7. Open the application in a web browser.
